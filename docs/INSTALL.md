# Installing MnemoScript

Everything below is produced by `npm run build:tauri` (Windows) and
`npm run android:build -- --apk` (Android), and copied into the repository's git-ignored
`release/` folder by the packaging step.

---

## Windows

### The easy way (recommended)

1. Open **`MnemoScript_2.0.0_x64-setup.exe`**.
2. Click through the wizard (it takes a few seconds).
3. MnemoScript now appears in your **Start menu** and on your **desktop** — open it like any other app.

That is the whole process. A few details worth knowing:

| | |
|---|---|
| **Admin rights** | Not needed. It installs only for your user account, so Windows never shows a UAC prompt. |
| **Where it goes** | `%LOCALAPPDATA%\MnemoScript` (i.e. `C:\Users\<you>\AppData\Local\MnemoScript`). |
| **Shortcuts** | Start menu + desktop. |
| **WebView2** | The app renders through Microsoft's WebView2, which ships with Windows 10/11. On a machine that lacks it, the installer downloads it silently. |
| **SmartScreen** | The installer is not code-signed with a commercial certificate, so Windows may show *"Windows protected your PC"*. Choose **More info → Run anyway**. Buying an EV code-signing certificate is the only way to remove that prompt. |

### Other options

| File | When to use it |
|---|---|
| `MnemoScript_2.0.0_x64_en-US.msi` | Group Policy / Intune / `msiexec /i MnemoScript_2.0.0_x64_en-US.msi` deployment. |
| `MnemoScript-2.0.0-portable-x64.exe` | No installation at all — copy it to a USB stick and run it. |

Scripted/silent install: `MnemoScript_2.0.0_x64-setup.exe /S`

### Updating

Run a newer setup `.exe`. It replaces the installed version in place; your projects are untouched.

### Uninstalling

**Settings → Apps → Installed apps → MnemoScript → Uninstall** (or run `uninstall.exe` in the install
folder). Your writing is **not** deleted — it lives in `%USERPROFILE%\.mnemoscript`, outside the app.

## Android

Tauri builds a normal Android app; it is simply not distributed through the Play Store yet, so you
sideload it.

1. Copy **`MnemoScript-2.0.0-arm64-release.apk`** to the phone (USB, Drive, email to yourself…).
2. Tap it in your file manager. Android asks to allow *"install unknown apps"* for that file manager —
   allow it, then go back and tap the APK again.
3. Play Protect may warn that the developer is unknown. Choose **Install anyway**.
4. MnemoScript appears in the app drawer.

Which APK:

| File | Notes |
|---|---|
| `MnemoScript-2.0.0-arm64-release.apk` | **The one you want** — 59 MB, arm64-v8a, which is every phone sold since roughly 2017. Built with `npm run android:build -- --apk --target aarch64`. |
| universal release APK | Contains all four CPU architectures (~237 MB). Build it with `npm run android:build -- --apk` only if a device refuses the arm64 build. |

> Size note: most of the APK is the bundled offline-speech payload (onnxruntime-web variants and the
> Whisper model under `app/public/`). Trimming the unused ORT variants is a tracked improvement — see
> [IMPROVEMENT_PLAN.md](./IMPROVEMENT_PLAN.md).

### Signing

Release APKs are signed with a key generated for this project at
`app/src-tauri/gen/android/keystore.jks` (git-ignored, with its passwords in `keystore.properties`
beside it).

> **Back that file up.** Android will only accept an update to an installed app if it is signed with
> the *same* key. Losing it means future versions cannot upgrade an existing install — users would have
> to uninstall first, losing nothing but convenience.

To rotate or recreate the key:

```bash
cd app/src-tauri/gen/android
keytool -genkeypair -v -keystore keystore.jks -alias mnemoscript \
        -keyalg RSA -keysize 2048 -validity 10000
```

then update `keystore.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`).
`gen/android` is regenerated by `tauri android init`; if that ever runs, re-apply the `signingConfigs`
block in `app/build.gradle.kts` and the `RECORD_AUDIO` permission in `AndroidManifest.xml`.

### Debug builds

`npm run android:build -- --apk --debug` produces a debug-signed APK that needs no keystore. It is
much larger (every architecture, plus debug symbols — 692 MB as measured) and is only meant for quick
testing over USB.

## Where your writing is stored

| Platform | Location |
|---|---|
| Windows | `%USERPROFILE%\.mnemoscript\projects` (or any folder you chose per project) |
| Android | App-private storage (removed when you uninstall the app) |

A project is a plain folder: `project.json` (metadata), `documents/<id>.json` (one file per document),
`assets/` (images), `exports/` (rendered maps). Back it up by copying the folder.
